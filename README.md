## About RyNxt

**[RyNxt](https://rynxt.com)** is an AI-driven Windows systems and latency optimization suite engineered for competitive esports gamers, high-refresh display owners, and workstation enthusiasts. It calibrates operating system dispatch routines, unlocks sub-millisecond timer resolutions, and stabilizes CPU core thread allocation to eliminate micro-stutters and drastically improve **1% Low FPS**.

Unlike traditional "one-size-fits-all" batch scripts that apply dangerous overclocks and corrupt registry keys, RyNxt deploys **Hardware-Aware Dynamic Tuning**. It analyzes machine architecture in real time (Desktop PC vs. Gaming Laptop), tracks thermal overhead, and balances voltage/power curves within manufacturer safety specifications.

## 🛠️ In-Depth Performance Tweaks

### 🧠 CPU & Kernel Scheduler Architecture
- **Timer Resolution Synchronization:** Forces precise NT kernel timer interrupts down to 0.5ms.
- **Power Throttling Bypass:** Disables Windows energy-saving heuristics on active 3D processes.
- **Dynamic Foreground Priority:** Demotes background telemetry and update workers to idle priority, dedicating hardware throughput to game threads.
- **BCD & Synthetic Timer Tuning:** Enforces real-time platform clock synchronization to eliminate synthetic software timing jitter.

### 🎮 GPU Pipeline & Driver Optimization
- **Message Signaled Interrupts (MSI Mode):** Converts graphics adapter interrupts to high-speed PCIe memory writes, eliminating bus conflicts.
- **Driver Telemetry Eradication:** Shuts down hidden diagnostic reporting services from NVIDIA, AMD, and Intel drivers to reclaim CPU cycles.
- **DirectX & DXGI Swap-Chain Optimization:** Cleans presentation queues for immediate frame dispatch and reduced display pipeline lag.
- **Automated DLSS / FSR Pipeline Sync:** Synchronizes game engine runtimes with the latest display driver libraries.

### 💾 Memory & NVMe Storage Subsystem
- **Dynamic Standby Memory Purge:** Clears orphaned standby cache pages before memory depletion triggers frame drops.
- **NVMe / SSD TRIM Optimization:** Calibrates storage block availability to ensure instant asset streaming in modern open-world games.
- **NTFS Polling Overhead Reduction:** Disables legacy 8.3 short-name generation, last-access timestamp writes, and background compression overhead.

### 🌐 Network Stack & Packet Priority
- **QoS Bandwidth Uncapping:** Removes default Windows network throttling reserves to utilize the full throughput of your network interface.
- **TCP/IP Congestion & Nagle's Bypass:** Forces immediate packet delivery (NoDelay) to minimize network buffer latency during online multiplayer sessions.
- **Built-in DNS & Route Benchmarking:** Evaluates low-latency DNS handshakes and profiles ping stability across global gaming datacenters.

## 🛠️ Build from Source

For developers, contributors, and security auditors wishing to build the project locally:

### Prerequisites
* [Node.js](https://nodejs.org/) (v18.0.0 or higher)
* [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)
* Windows 10/11 Developer Environment with PowerShell 7+

### Step-by-Step Build
```bash
# Clone the official repository
git clone [https://github.com/mohammad-javad-asadi/revx.git](https://github.com/mohammad-javad-asadi/revx.git)
cd revx

# Install project dependencies
npm install

# Start the application in development mode
npm run dev

# Compile production installer for Windows (64-bit)
npm run build:win
